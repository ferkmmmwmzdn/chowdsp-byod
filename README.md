## Overview

BYOD is a free, open-source, modular guitar effects plugin with a node-based signal flow editor and over 50 analog-modeled effect modules for building any custom pedalboard chain.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **ChowDSP BYOD** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Node Graph** | Connect effects with drag-and-drop cables in a visual signal flow editor |
| **50+ Modules** | Distortion, fuzz, reverb, delay, EQ, compressor, and more models |
| **Analog Models** | Circuit-level models of classic pedals using Kirchhoff network equations |
| **Stereo Paths** | Route stereo and mono signal paths independently through the graph |
